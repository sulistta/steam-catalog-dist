# Steam catalog

The independent catalog client is in development. Signed community catalog
snapshots are available in [Releases](https://github.com/sulistta/steam-catalog-dist/releases).
The [update index](index-v1.json) identifies the current snapshot; entries have
not all been tested as installable or playable games.

There are no installers yet. Windows and Linux downloads will appear after
compatibility and restoration checks have passed for each platform.
